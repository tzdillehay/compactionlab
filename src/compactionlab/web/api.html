LOCAL CONTEXT SERVICE

API reference

Append immutable source events and records, then retrieve a bounded context bundle. HTTP and MCP use the same store.

Endpoints

Method Path Purpose
GET /api/health Service health
GET /api/models Installed Ollama models
GET /api/namespaces List task scopes
GET /api/namespaces/{name} Inspect records and original sources
POST /api/namespaces/{name}/records Atomic version-checked append
POST /api/namespaces/{name}/context Retrieve plain, verbose structured, or compact shared-source context
POST /api/jobs Start a local comparison
GET /api/jobs/{id} Observe job progress
GET /api/runs List saved runs
GET /api/runs/{id} Read full run data
POST /api/qualification/jobs Start receiver capability calibration
GET /api/qualifications List saved capability studies
GET /api/qualifications/{id} Read all capability outcomes and settings

Write example

{
  "expected_revision": 0,
  "events": [{"id": "user-1", "source": "user", "text": "Contact me by SMS."}],
  "records": [{"id": "contact-1", "kind": "requirement", "text": "Contact by SMS",
               "source_ids": ["user-1"]}]
}

POST this JSON to /api/namespaces/demo/records. A stale expected_revision returns 409. Unknown references return 400 and roll back the whole batch.

Retrieve example

{"query": "contact method", "mode": "structured", "byte_budget": 6000}

POST this JSON to /api/namespaces/demo/context. The result includes text, byte count, record IDs, omitted count and snapshot revision. Use mode "compact" for sparse records and a shared source table. It preserves source text and dependency groups; empty fields are omitted.

This service is for one trusted local user. Namespace names do not provide authentication. Records are claims, not guaranteed truths. No paid provider or arbitrary execution endpoint exists.
